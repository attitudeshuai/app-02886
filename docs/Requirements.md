# 需求文档：Git 仓库文档抓取工具

## 1. 项目概述

**项目名称**: Git Doc Fetcher  
**技术栈**: Python  
**目标**: 开发一个可以抓取 Git 仓库文档的工具，提供 Web 界面进行操作和浏览

---

## 2. 核心功能需求

### 2.1 仓库抓取功能
- **输入**: 用户提供 Git 仓库 URL（支持 GitHub、GitLab、Gitee 等公开仓库）
- **抓取方式**: 使用 `git clone --depth=1` 浅克隆，仅获取最新版本
- **支持的文档格式**:
  - Markdown (.md)
  - 纯文本 (.txt)
  - reStructuredText (.rst)
  - 其他常见文档格式

### 2.2 文档管理功能
- **多仓库管理**: 支持添加、删除、刷新多个仓库
- **文档索引**: 自动扫描并索引仓库中的文档文件
- **分类展示**: 按目录结构展示文档树

### 2.3 文档浏览功能
- **Markdown 渲染**: 支持完整的 Markdown 语法渲染
- **代码高亮**: 文档中的代码块支持语法高亮
- **目录导航**: 自动生成文档内目录 (TOC)

### 2.4 搜索功能
- **全文搜索**: 在已抓取的文档中进行关键词搜索
- **搜索结果高亮**: 高亮显示匹配的关键词

### 2.5 文档导出功能
- **单文档导出**: 支持导出单个文档为 Markdown 格式
- **批量导出**: 支持导出整个仓库文档为 ZIP 压缩包

> ⚠️ PDF 导出功能因依赖库兼容性问题，经用户确认后移除

---

## 3. 技术架构

### 3.1 后端 (Backend)
- **框架**: FastAPI (Python)
- **功能**:
  - Git 仓库克隆与更新
  - 文档解析与索引
  - RESTful API 提供数据服务

### 3.2 前端 (Frontend)
- **框架**: React + TypeScript
- **UI 组件库**: Tailwind CSS + Shadcn/UI
- **功能**:
  - 仓库管理界面
  - 文档浏览器
  - 搜索界面

### 3.3 数据存储
- **文档存储**: 文件系统 (本地目录)
- **元数据存储**: SQLite (轻量级，无需额外服务)

---

## 4. 非功能需求

### 4.1 Docker 交付标准
- 必须支持 `docker compose up --build -d` 一键启动
- 支持 ARM64 (Apple Silicon) 和 AMD64 (x86) 架构
- 前端服务端口: 8081
- 后端服务端口: 8000

### 4.2 界面设计标准
- 现代化、简洁的 UI 设计
- 响应式布局，适配不同屏幕尺寸
- 良好的用户交互反馈
