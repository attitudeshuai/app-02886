# 设计规范：Git Doc Fetcher

## 1. 设计理念

**风格**: 极简灰调 + 卡片式布局  
**参考**: Metro UI 风格（参见 assets 目录参考图）  
**核心原则**: 干净、留白、柔和、专业

---

## 2. 色彩系统

### 2.1 核心色板（来自参考图）
| 名称 | 色值 | 用途 |
|------|------|------|
| **Primary** | `#515d6d` | 主色调、导航、重要文字 |
| **Primary Light** | `#6b7a8a` | 悬停状态、次要强调 |
| **Primary Dark** | `#3d4654` | 按下状态、深色标题 |

### 2.2 背景色系
| 名称 | 色值 | 用途 |
|------|------|------|
| **Background** | `#f7f7f7` | 页面主背景 |
| **Surface** | `#ffffff` | 卡片、面板背景 |
| **Surface Alt** | `#eeeeee` | 侧边栏、次级面板 |

### 2.3 文字色系
| 名称 | 色值 | 用途 |
|------|------|------|
| **Text Primary** | `#515d6d` | 主要标题、导航文字 |
| **Text Secondary** | `#8a939e` | 正文内容 |
| **Text Muted** | `#b8bfc7` | 占位符、禁用态、时间戳 |

### 2.4 分割与边框
| 名称 | 色值 | 用途 |
|------|------|------|
| **Border** | `#e8e8e8` | 卡片边框、分割线 |
| **Divider** | `#eeeeee` | 列表分割线 |

### 2.5 点缀色（功能性）
| 名称 | 色值 | 用途 |
|------|------|------|
| **Accent** | `#4ca6cf` | 图标高亮、链接、选中态 |
| **Accent Light** | `#e8f4f9` | 选中背景 |
| **Success** | `#5cb85c` | 成功状态 |
| **Warning** | `#f0ad4e` | 警告状态 |
| **Error** | `#d9534f` | 错误状态 |

## 3. 字体系统

### 3.1 字体家族
```css
--font-sans: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif;
--font-mono: 'SF Mono', 'Monaco', 'Inconsolata', 'Fira Code', monospace;
```

### 3.2 字号规范
| 级别 | 大小 | 字重 | 颜色 | 用途 |
|------|------|------|------|------|
| H1 | 28px | 500 | Text Primary | 页面标题 |
| H2 | 22px | 500 | Text Primary | 区块标题 |
| H3 | 18px | 500 | Text Primary | 卡片标题 |

| XSmall | 11px | 400 | Text Muted | 元信息 |

## 6. 页面布局

### 6.1 整体结构
```
+----------------------------------------------------------+
|  Header (h: 56px) - 白色背景 + 底部阴影                    |
|  Logo + 搜索框 + 操作按钮                                  |
+------------+---------------------------------------------+
|            |                                             |
|  Sidebar   |           Main Content                      |
|  (w: 280)  |           背景: #f7f7f7                      |
|  背景:     |                                             |
|  #ffffff   |    +----------------------------------+     |
|            |    |        Content Card              |     |
|  列表导航   |    |        背景: #ffffff             |     |
|            |    |        内边距: 24px              |     |
|            |    +----------------------------------+     |
|            |                                             |
+------------+---------------------------------------------+
```

### 6.2 侧边栏设计
- 宽度: 280px
- 背景: `#ffffff`
- 右边框: `1px solid #eeeeee`
- 列表项高度: 48px
- 分组标题: 12px, `#b8bfc7`, 大写字母间距

### 6.3 响应式断点
| 断点 | 宽度 | 行为 |
|------|------|------|
| Mobile | < 768px | 侧边栏隐藏，抽屉式菜单 |
| Tablet | 768-1200px | 侧边栏收缩至图标模式 (60px) |
| Desktop | > 1200px | 完整侧边栏 |

## 7. 文档阅读区设计

### 7.1 Markdown 渲染样式
```
容器:
- 最大宽度: 800px
- 内边距: 32px 40px
- 背景: #ffffff
- 圆角: 8px

标题:
- H1: 28px, #515d6d, 底部边框 1px #eeeeee, margin-bottom: 24px
- H2: 22px, #515d6d, margin-top: 32px
- H3: 18px, #515d6d

正文:
- 字号: 15px
- 行高: 1.75
- 颜色: #5a6370
- 段落间距: 16px

代码块:
- 背景: #2d3748
- 前景: #e2e8f0
- 圆角: 6px
- 内边距: 16px
- 字体: mono, 13px

行内代码:
- 背景: #f7f7f7
- 颜色: #515d6d
- 圆角: 4px
- 内边距: 2px 6px

链接:
- 颜色: #4ca6cf
- 无下划线
- 悬停: 下划线

引用块:
- 左边框: 3px solid #4ca6cf
- 背景: #f7f7f7
- 内边距: 12px 16px
- 文字颜色: #8a939e
```

### 7.2 目录导航 (TOC)
```
位置: 右侧固定
宽度: 200px
字号: 13px
行高: 2

默认: #8a939e
悬停: #515d6d
激活: #4ca6cf + 左边框 2px
```

## 8. 图标规范

### 8.1 图标风格
- 风格: 线性图标 (Outline)
- 推荐库: Lucide Icons / Heroicons
- 默认尺寸: 20px
- 默认颜色: `#8a939e`
- 激活颜色: `#4ca6cf`

### 8.2 图标容器
```
小型: 32px × 32px, 圆角 6px
中型: 40px × 40px, 圆角 8px
大型: 48px × 48px, 圆角 10px
背景: #f7f7f7
```
